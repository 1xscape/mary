LESSON 1 - MY ONLINE PERSONALITY
================================
Student interactive English lesson (23 pages, previous pages 22 and 25 removed).

OPEN
  Double-click index.html. All HTML, CSS and JS are bundled in the same folder.
  No build step, server, or installation is required.

WHAT'S NEW
  * Multiple-choice answers, checked dropdowns, checklists, and matching meanings
    are shuffled per question but remain in the same order between revisits.
  * Image URLs use public Unsplash and Pexels CDNs with a backup host per image
    and an embedded illustration fallback. Photo and YouTube streaming need internet.
  * Automatically shows correct answers once three attempts have been used.
  * Correct answers play a two-tone ding; mistakes play a soft short buzzer.
  * Completed matching pairs animate to the bottom of the board.
  * Vocabulary word banks support click-to-place and drag-and-drop.
  * Grammar on the original pages 15 and 21 uses in-sentence dropdowns.
  * Original page 18 uses draggable sentence tiles and a CHECK button.
  * Original page 13 features an independently written simplified adaptation
    based on a real Sarah Spellings Vogue article from December 22, 2021.
    https://www.vogue.com/article/tiktok-algorithm
  * Sasha, Kirill, Kristina and familiar celebrity names appear in exercises.
  * Learner data (except removed pages) is stored locally in the browser.

DEPENDENCIES
  Files: index.html, app.js, styles.css. Keep them in the same folder.
  An internet connection is necessary to display online photographs or videos.
  When online photos cannot be fetched, an embedded SVG illustration appears.
  Interaction audio uses the browser's Web Audio API after the student's first action.
